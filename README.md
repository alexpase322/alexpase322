## 🚀 Proyectos destacados

**[Jornixs — Backend](https://github.com/alexpase322/jornixs_backend)** · [jornixs.com](https://www.jornixs.com)
Backend de un SaaS de control horario y nómina en producción. Spring Boot 3.5 con arquitectura por capas, autenticación JWT con control de acceso por roles, pagos y suscripciones con Stripe, reportes en PDF y Excel, envío de correos y despliegue con Docker sobre PostgreSQL. Lógica de nómina cubierta con pruebas unitarias en JUnit 5 y Mockito.

**[Platzi Play API](https://github.com/alexpase322/platziplay)** · [Demo con Swagger](https://platziplay-tod8.onrender.com/platzi-play/api/swagger-ui/index.html)

**[Monitorías Académicas](https://github.com/alexpase322/monitorias)**
Base del backend para la gestión de monitorías de la Universidad Surcolombiana: modelo de dominio de 17 entidades JPA y capa de acceso a datos sobre SQL Server.
