## 🚀 Proyectos destacados

### ⏱️ [Jornixs — Backend](https://github.com/alexpase322/jornixs_backend) · [jornixs.com](https://www.jornixs.com)

Backend de un SaaS de control horario y nómina **en producción**: registro de jornadas con geolocalización, cálculo de horas extra, aprobación semanal y suscripciones de pago.

- Spring Boot 3.5 y Java 17 con arquitectura por capas: 11 controladores REST, 15 servicios y 11 entidades JPA.
- Autenticación JWT con control de acceso por roles mediante `@PreAuthorize`.
- Pagos y portal de suscripción con **Stripe**, incluidos webhooks.
- Reportes de nómina en **PDF (OpenPDF)** y **Excel (Apache POI)**, envío de correos y almacenamiento de archivos en Cloudinary.
- Lógica de nómina y jornadas cubierta con **pruebas unitarias en JUnit 5 y Mockito**.
- Configuración sensible 100 % externalizada en variables de entorno y despliegue con **Docker**.

`Java 17` `Spring Boot` `Spring Security` `JPA` `PostgreSQL` `Stripe` `Docker` `JUnit 5` `Mockito`

### 🎬 [Platzi Play API](https://github.com/alexpase322/platziplay) · [Demo en vivo con Swagger](https://platziplay-tod8.onrender.com/platzi-play/api/swagger-ui/index.html)

API REST de catálogo de contenido con integración de inteligencia artificial dentro del ecosistema Java.

- Persistencia con Spring Data JPA y mapeo de DTO con **MapStruct**.
- Funcionalidades de IA integradas con **LangChain4j** y OpenAI.
- Perfiles de configuración separados para desarrollo y producción, contenerizada con Docker Compose y desplegada en Render.
- Documentación interactiva con Swagger / OpenAPI.

`Java` `Spring Boot` `Gradle` `PostgreSQL` `LangChain4j` `MapStruct` `Docker` `Render`

### 🎓 [Monitorías Académicas](https://github.com/alexpase322/monitorias)

Base del backend para gestionar el ciclo de monitorías de la Universidad Surcolombiana: ofertas, solicitudes de estudiantes, pruebas de selección, factores de calificación y seguimiento de actividades.

- Modelo de dominio de 17 entidades JPA con identificadores UUID y borrado lógico.
- Capa de acceso a datos con el patrón DAO y consultas JPQL sobre SQL Server.

`Java 17` `Spring Boot` `JPA / Hibernate` `SQL Server`
